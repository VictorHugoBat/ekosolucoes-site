# Pasta `assets/`

Esta pasta é reservada para arquivos-fonte e materiais brutos do projeto que
**não** são carregados diretamente pelo site, por exemplo:

- Logotipo em alta resolução (.ai, .svg original, .psd);
- Fotos originais antes de serem comprimidas e movidas para `/images`;
- Documentos internos de marca (paleta de cores, manual de identidade).

Arquivos realmente usados pelo site (imagens finais, favicons, ilustrações)
devem ficar em `/images`. Ícones de interface (SVG) ficam em `/icons`.

Esta pasta está vazia por padrão — adicione aqui os arquivos-fonte da Eko
Soluções conforme a empresa for fornecendo materiais reais (fotos da equipe,
fotos de antes/depois dos serviços, logotipo oficial etc.).
